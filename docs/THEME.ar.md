## قواعد الصفحة

- محّذ كل المحتوى إلى اليسار. لا توسّط صفحة README بالكامل.
- قل في العنوان ما الذي يفعله المستودع. احذف الكلمات المبالغ فيها والنعوت التي تروّج.
- ضع رابط إجراء واحد رئيسي. لا تكدّس الأزرار.
- استخدم شبكة من أربع نقاط بعبارات حقيقية. كل صف يجب أن يقول شيئاً واقعياً.
- احتفظ بلحظة إضاءة واحدة: شريط عنبر واحد في اللافتة، أو حالة نشطة واحدة. بقية الأسطح مسطّحة.
- لا تستخدم تدرجات، أو نصوصاً متدرجة، أو توهجاً، أو أشكالاً لامعة، أو حركة، أو أي رسوم متحركة.
- لا تستخدم الرموز التعبيرية في العناوين أو التنقل أو روابط الإجراء أو البطاقات.
- لا تستخدم خط Inter في الصفحة أو اللافتة. استخدم خط GitHub الافتراضي للنص وخطاً أحادي المسافة في SVG.
- لا تضف بطاقات إحصاءات أو رسوم مساهمات أو بطاقات مستودعات مثبّتة أو صفوف شارات أو آراء مزعومة.
- لا تكتب تعليقات صغيرة بحروف كبيرة أو صناديق أيقونات.
- تبقى تطبيقات الهندسة على مظهرها الفاتح الأصلي.
- يستخدم المحررون والطرفيات مظهر Graphite Amber أساساً. يمكن بقاء المظاهر القديمة الاختيارية داخل منتقي مظهر لينكس فقط، وليست هي الافتراض ولا تُستخدم في المستندات أو اللافتات أو الشارات.
- لا تضف عائلة مظهر أخرى أو حزمة أيقونات إلى المستندات أو اللافتات أو المحررين أو الطرفيات.
- الإنجليزية هي المعيار. العربية هي الترجمة الوحيدة. لا نصوص صينية.

## تخطيط الصفحة

| الجزء | القاعدة |

| اللافتة | SVG رمادي مسطّح، شريط عنبر واحد، عنوان وسطران واقعيان |

| الإجراء | رابط واحد يبدأ بفعل ويشير إلى الدليل السريع أو المستندات |
| الشبكة | أربعة صفوف، كل صف تسمية وعبارة حقيقية |
| التفاصيل | إبقاء الأقسام التقنية الموجودة أسفل الشبكة |

أُزيلت بطاقات الإحصاءات وبطاقات السلسلة وبطاقات اللغات وبطاقات المستودعات المثبّتة. أُزيلت صفوف الشارات فوق العنوان.

## ملفات ويندوز

- VSCodium: ألوان Graphite Amber مخصّصة على الأساس الداكن المدمج، مع مؤشر وحدود نشطة بلون العنبر.
- Windows Terminal: Graphite Amber هو المخطط الافتراضي والوحيد.
- واجهة Windows وتطبيقات الهندسة: مظهر فاتح أصلي، بلا شفافية، مع تقليل الحركة.
