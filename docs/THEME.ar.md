## القواعد

- اجعل الخلفيات درجات جرافيت هادئة منخفضة التباين. تجنب الأسود الخالص والأبيض الساطع.
- استخدم العنبر مرة واحدة في كل شاشة. إذا كان العنوان عنبريا، اجعل الحدود هادئة.
- اجعل النص الأساسي رماديا دافئا. لا تستخدم تدرجات نيون أو تأثيرات توهج.
- تبقى تطبيقات الهندسة على مظهرها الفاتح الأصلي.
- يستخدم المحرر والطرفية Graphite Amber كأساس. قد تبقى لوحات قديمة اختيارية داخل أدوات اختيار الثيم على Linux فقط؛ ليست الافتراضية ولا تُستخدم في الوثائق أو اللافتات أو الشارات.
- لا تضف عائلة ألوان أخرى أو حزمة أيقونات إلى الوثائق أو اللافتات أو الشارات أو المحرر أو الطرفية. اللوحات القديمة الموجودة بالفعل في منتقيات ثيمات Linux مستثناة.
- لا تترجم أسماء الألوان. الإنجليزية هي المرجع، والعربية هي الترجمة الوحيدة.
- لا تضف نصوصا صينية.

## بطاقات GitHub

استخدم قيم الاستعلام هذه لإحصاءات اللغات والمستودعات المثبتة:

```text

title_color=e8a33d

```

بطاقة سلسلة المساهمات تستخدم القيم نفسها مع `theme=github_dark`. الشارات تستخدم `style=for-the-badge` حيث يناسب ذلك.

## ملفات Windows

- VSCodium: ألوان Graphite Amber مخصصة فوق الأساس الداكن المدمج، مع مؤشر وحد نشط عنبريين.
- Windows Terminal: Graphite Amber هو المخطط الافتراضي والوحيد.
- واجهة Windows وتطبيقات الهندسة: فاتحة أصلية، شفافية مغلقة، حركة مخفضة.
